# TestMu AI

Official plugin for [TestMu AI](https://www.testmuai.com) (formerly LambdaTest). It connects Droid to TestMu AI's hosted MCP server, so you can run, debug and triage tests on the TestMu AI cloud without leaving the session.

## What you can do

- **HyperExecute:** list jobs, read stage and task logs, download artifacts, analyze a failed job, and generate HyperExecute YAML
- **Automation triage:** read command, network, browser console and Selenium logs, screenshots and video for a test session
- **SmartUI:** query projects and builds, analyze visual comparisons, review screenshots and manage baselines
- **Analytics:** flaky tests, test trends and error categories
- **Accessibility:** fetch accessibility reports
- **Mobile apps:** upload apps and list devices available for testing
- **Test Manager:** projects, folders, test cases, test runs, milestones, AI-generated test cases, and Jira or Azure DevOps issue links

## Setup

1. Install the plugin.
2. Run `/mcp` and sign in to your TestMu AI account in the browser. The server uses OAuth, so there is no API key to paste.

You need a TestMu AI account. Tools that run tests use the execution minutes on your plan.
