# interrogate

Adversarial review where a finding survives only when a run proves it.

**Skills:**

- `interrogate` - Fan out adversaries to break a change or design; report only findings verified by rerunning their commands

Adapted from the pstack skills by Lauren Tan ([cursor/plugins](https://github.com/cursor/plugins), MIT License), with the fan-out rewritten to be harness-agnostic.
