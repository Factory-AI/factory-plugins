# blast-radius

Find what a change could break somewhere else before it ships, beyond the diff, and prove the one fact it's safe because of by running real code.

**Skills:**

- `blast-radius` - Assess what a change could break beyond the diff, with the one safety fact proven by a run, not a writeup

Adapted from the pstack skills by Lauren Tan ([cursor/plugins](https://github.com/cursor/plugins), MIT License), with Cursor-specific tooling removed and Droid conventions applied.
