# Disk cleanup safety cases

Tabletop controls, not instructions to delete test fixtures. Check the workflow
against these cases without running destructive commands.

| Case                                                                                                                           | Required outcome                                                                                                                                |
| ------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| Clean checkout, open PR, exact dependency-inclusive permission, owner release, preserved branch/store, all physical gates pass | Allow one normal non-force removal attempt. No PR merge or closure required.                                                                    |
| Modified/staged source or untracked evidence                                                                                   | Hold until complete approved preservation and reconstruction checks pass. A clean HEAD alone is insufficient.                                   |
| Human permits source-only cleanup; ignored installed dependencies exist                                                        | Block the whole-copy operation. Do not infer permission for dependencies.                                                                       |
| Installed dev wrapper falls back to this path; no accessible process currently uses it                                         | Block this target. No automatic wrapper edit or relocation; independent qualified targets may proceed.                                          |
| Unknown nested cache or private credential file                                                                                | Preserve and block, without reading or uploading secret contents. A dependency exception does not waive protection.                             |
| Tracked code directory named `credentials`, with no private/untracked file                                                     | Resolve the directory-name false positive using metadata and provenance; do not exempt a real private file.                                     |
| Removed checkout shares hardlinked dependencies with a retained checkout                                                       | Report observed available-space change, not the removed folder's nominal allocation or a sum of copies.                                         |
| Git refuses normal removal                                                                                                     | Stop. No force, manual recursive dependency deletion, or workaround under the same permission.                                                  |
| Deletion succeeds, then filesystem statistics or another post-check fails                                                      | Retain the already flushed local native result and report verification incomplete. Persist follow-up results separately; never repeat deletion. |
| Deletion completes, then shared publication returns 503                                                                        | Use the locally durable native result and physical checks. Never repeat deletion. Read first if a publication write's outcome is unknown.       |
| Native result was lost before publication                                                                                      | Record exit UNKNOWN and independently verify absence, registration and preservation; do not fabricate success status or rerun deletion.         |
| User changes a file after qualification                                                                                        | Invalidate the seal and reassess. Do not overwrite, discard, or archive the new work without permission.                                        |
| Partial scan returns nonzero but its parser returns zero                                                                       | Retain native error/coverage limits; do not label the scan complete or attribute missing usage to an invented folder.                           |
| Available space rises above a historical warning threshold                                                                     | Report measured availability. Warning clearance remains UNKNOWN without current UI/monitor evidence.                                            |
