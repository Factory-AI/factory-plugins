# correct

Find the mistakes agents keep repeating in a repo and make each one impossible.

**Skills:**

- `correct` - Architecture first, then types, then a lint whose error names the fix, then a test, docs last; prove each check fails on a real past mistake

Adapted from the pstack skills by Lauren Tan ([cursor/plugins](https://github.com/cursor/plugins), MIT License), with Cursor-specific tooling removed and Droid conventions applied.
