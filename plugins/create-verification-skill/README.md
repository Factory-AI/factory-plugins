# create-verification-skill

Generate a project-local verification skill and feature map that drives the app the way a user does, any language, framework, or platform.

**Skills:**

- `create-verification-skill` - Interview the repo, scaffold a launch/doctor/drive/evidence/cleanup skill plus a per-feature map, and prove it end to end before handover

Ships a worked `references/feature-map-example/` (index plus per-feature recipes).

Pairs with `droid-control`'s `/verify` command (runtime driving) and the `maintain-verification-skill` plugin (upkeep loop).

Adapted from the pstack skills by Lauren Tan ([cursor/plugins](https://github.com/cursor/plugins), MIT License), with project-skill paths updated for Droid (`.factory/skills/`).
