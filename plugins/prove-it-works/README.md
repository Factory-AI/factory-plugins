# prove-it-works

Behavioral guardrail: verify every task output against the real artifact before declaring done.

**Skills:**

- `prove-it-works` - Verify against the real artifact (run the feature, read the actual value, inspect the diff), not a proxy, self-report, or "it compiles"

Adapted from the pstack skills by Lauren Tan ([cursor/plugins](https://github.com/cursor/plugins), MIT License), with Cursor-specific tooling removed and Droid conventions applied.
