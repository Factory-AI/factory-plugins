# maintain-verification-skill

Keep a project's verification skill and feature map honest as the app changes.

**Skills:**

- `maintain-verification-skill` - Source wave per feature, live pass over every feature, and at most one PR of proven corrections; reports clean, changed, or blocked

Companion to the `create-verification-skill` plugin, which generates the verification skill this pass maintains.

Adapted from the pstack skills by Lauren Tan ([cursor/plugins](https://github.com/cursor/plugins), MIT License), with project-skill paths updated for Droid (`.factory/skills/`).
